# Squad: DashAds-Ulbra Core

## Overview
Esta squad foi projetada para sustentar o ecossistema de Business Intelligence da Ulbra, focada em anúncios digitais (Meta/Google).

## Agents
- **@data-engineer (Flux):** Orquestração de dados e SQL.
- **@analyst (Adriel):** BI Intelligence, estratégia de mídia e insights.
- **@dev (Dex):** Implementação full-stack e integração.
- **@ux-design-expert (Aura):** Visualização de dados e interfaces UI.
- **@architect (Skye):** Arquitetura, modularidade e escalabilidade.
- **@devops (Gage):** Infraestrutura, Docker e automação de deploy.
- **@pm (Morgan):** Requisitos de produto, PRDs e estratégia.
- **@qa (Quinn):** Auditoria de cálculos e integridade.

- **@sm (River):** Entrega e coordenação.

### Product Agents (Runtime AI)
- **@creative-analyst-ai (Gaia):** IA de análise de criativos (Gemini LLM).


## Tech Stack

- Frontend: React + Vite + Tailwind + shadcn/ui
- Backend: Supabase (PostgreSQL)
- Visualization: Recharts
- Analytics: Meta Graph API (Planned)

## Core Workflows
1. **Data Consistency:** Flux -> Adriel -> Aura
2. **Performance Audit:** Adriel -> Quinn
